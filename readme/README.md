# Salvito O Saltarico – Website

Website institucional para o projeto **Salvito O Saltarico**, dedicado ao aluguer de insufláveis e animação de eventos.

##  Descrição

Este projeto consiste num website moderno e responsivo desenvolvido com **HTML, CSS, Bootstrap e JavaScript**, com o objetivo de apresentar serviços, galeria de atividades e facilitar o contacto com clientes.

O site foi desenhado com foco em:

* Experiência do utilizador (UX)
* Design moderno e apelativo
* Navegação simples e intuitiva
* Conversão de visitantes em clientes

---

## Funcionalidades

### Página Inicial 

* Secção Hero com destaque da marca
* Apresentação dos serviços:

  * Insufláveis
  * Trampolins
  * Jogos
  * Pinturas faciais
  * Balões
  * Animação
* Botão de contacto rápido (WhatsApp e Email)
* Animações ao scroll (IntersectionObserver)

### Galeria 

* Grid responsiva com imagens
* Efeito hover com overlay informativo
* Secção de testemunhos de clientes
* Call-to-action para redes sociais

### Contacto 

* Formulário de contacto com validação básica
* Modal de sucesso após envio
* Redirecionamento automático após submissão
* Interface limpa e intuitiva
